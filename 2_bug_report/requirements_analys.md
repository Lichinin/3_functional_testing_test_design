## Отчет по тестированию требований

### Часть 1. UI
|Требование|Проблема|Рекомендация|Статус|
|---|---|---|---|
|"Если файл находится в корзине - он так же может быть найден поиском"|Неполнота: Нет уточнения, должен ли файл отображаться с пометкой "в корзине".|Указать, как файл из корзины должен отображаться в результатах (например, с иконкой корзины).|Требует уточнения|
|"Вслучае, если нет файлов, удовлетворяющих запросу, получено сообщение "В вашем Диске не найдено файлов или папок по запросу <.......>"|Опечатка: `Вслучае` -> В случае|Исправить опечатку|Требует доработки|

### Часть 2. API
|Требование|Проблема|Рекомендация|Статус|
|---|---|---|---|
|"В случае успешного выполнения запроса получен ответ 200, папка появилась по нужному адресу в диске"|Некорректность: По стандарту REST, при создании ресурса должен возвращаться `201 Created`|Исправить на `201 Created`|Критично|
|"При попытке создания уже по существующему пути - ответ `400`"|Некорректность: По стандарту REST, конфликт существования ресурса — это `409 Conflict`|Исправить на `409 Conflict`|Критично|
|"параметры строки запроса:<br>path - Путь к создаваемой папке<br>fields - Список возвращаемых атрибутов"|Неполнота: Не указано, какие атрибуты доступны.|Добавить список допустимых значений|Требует уточнения|
