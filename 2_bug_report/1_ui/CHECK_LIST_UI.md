## Чек-лист: Тестирование функции поиска (UI)
### Общая информация
**Тестируемый модуль:** Поиск файлов и папок
**Инструмент:** Веб-интерфейс Яндекс.Диска
**Предусловия:**
- У пользователя есть аккаунт в Яндексе
- Пользователь вошёл в аккаунт
- На диске загружены два файла:
`Created_!@#$%^&().txt` (в корне)
`Deleted_!@#$%^&.txt` (в корзине)


|№| Название проверки | Ожидаемый результат | Статус |
|---|---|---|---|
| 1 | Поиск точного совпадения имени файла  | В результатах поиска отображается искомый файл |&check;|
| 2 | Поиск по части имени                  | В результатах поиска отображается искомый файл |&check;|
| 3 | Поиск без совпадений                  | В результатах поиска отсутствуют файлыи папки |&check;|
| 4 | Поиск с использованием специальных символов | В результатах поиска отображается искомый файл |&check;|
| 5 | Поиск файла из корзины                | В результатах поиска отображается искомый файл |&cross;|
