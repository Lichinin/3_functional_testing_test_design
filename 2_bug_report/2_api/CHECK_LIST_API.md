## Чек-лист: API Тестирование
### Общая информация
**Цель:** протестировать REST API метод создания папки через Yandex.Disk API.
**Метод:** `PUT https://cloud-api.yandex.net/v1/disk/resources`
**Заголовки:**
Content-Type: application/json
Authorization: OAuth [your_token]
**Параметры запроса:**
`path` — путь к новой папке (например /new_folder)
`fields` — список возвращаемых атрибутов (опционально)

|№  | Название проверки                                 | Ожидаемый результат   | Статус    |
|---|---------------------------------------------------|-----------------------|-----------|
| 1 | Успешное создание папки                           | 200 OK, папка создана |&cross;    |
| 2 | Некорректный токен                                | 401 Unauthorized      |&check;    |
| 3 | Пустой токен                                      | 401 Unauthorized      |&check;    |
| 4 | Создание папки с некорректными символами (`/:?`)  | 400 Bad Request       |&check;    |
| 5 | Создание папки с существующим именем              | 400 Bad Request       |&cross;    |
| 6 | Некорректный путь                                 | 400 Bad Request       |&check;    |
| 7 | Тело ответа при ошибке                            | { "message": "string", "description": "string", "error": "string" }|&check;|
