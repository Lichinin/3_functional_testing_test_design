## 1. Общие сведения
|   |   |
| :------------ | :------------ |
|Название тест-плана|Тестирование GET-запроса /products/{productId}/status?authToken=&recalculate=&owner=&region=|
|Описание|Проверка корректности работы REST API получения статуса продукта|
|Участники|QA-инженеры|
|Среда тестирования|{server_name}|
|Инструменты|Postman|

## 2. Цель тестирования
Проверить:

- Авторизацию через **authToken**
- Обработку параметров: **recalculate, owner, region**
- Возврат правильного статуса продукта
- Обработку ошибок: 404, 500
- Формат ответа в JSON

## 3. Подход к тестированию
- Ручное тестирование
- Pairwise Testing для комбинаций параметров
- Проверка отсутствия параметров
- Проверка authToken

## 4. Категории тест-кейсов
|Категория|Описание|
| :------------ | :------------ |
|authToken|Проверка авторизации|
|Pairwise|Комбинации параметров recalculate, owner, region|
|Отсутствие параметров|Проверка работы API при отсутствии одного или нескольких параметров|

## 5. Предусловия
- Сервер доступен по адресу **{server_name}**
- Продукт с ID **{validId}** существует
- Имеется валидный токен длиной 16 символов (буквы и цифры)
